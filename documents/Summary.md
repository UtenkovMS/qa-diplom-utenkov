# Отчет по итогам автоматизации

***

## Запланировано

*Цель:* 

Автоматизация тестирования вэб-приложения покупки тура по дебетовой и кредитной карте.

*Задачи:*
1. Написать тестовые сценарии проверок.
2. Настроить тестовое окружение.
3. Обеспечить тестовое покрытие приложения.
4. Сформировать отчет об ошибках по итогам тестирования.

## Реализовано

1. Написан тестовый план, в который вошли 74 тестовых сценария.
2. Настроено тестовое окружение:
- build.gradle
- docker-compose.yml
- application.properties
- application-postgres.properties
3. Реализованы 163 автотеста.
4. Написан отчет по итогам тестирования.

## Риски

1. Значительное время при подготовке окружения заняла настройка и отладка docker-compose.yml, gradle.yml для CI GitHub сразу для двух СУБД.
2. В требованиях к дипломному проекту не было четких рекомендаций по тестовому покрытию. Можно было написать как много, так и небольшое число автотестов. 
3. В требованиях к дипломному проекту не было сказано о реализации тестирования API. Принял решение написать автотесты API, которые выявили баги при взаимодействии приложения с сервером.

## Потенциал для развития

Для удобства и лучшей структуры проекта API и UI тесты писать в разных классах.
Писать более короткие, емкие и однородные названия автотестов.
